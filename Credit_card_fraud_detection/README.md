# Credit Card Fraud Detection

## Overview
This project aims to identify fraudulent credit card transactions using machine learning techniques.

## Dataset
The dataset contains transaction records labeled as fraudulent or genuine.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Project Steps
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Data Normalization
5. Model Training
6. Model Evaluation

## Model Used
- Logistic Regression

## Results
The model was evaluated using Accuracy, Precision, Recall, and F1-Score to detect fraudulent transactions.
