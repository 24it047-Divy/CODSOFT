# Iris Flower Classification

## Overview

This project aims to classify Iris flowers into three species: Setosa, Versicolor, and Virginica using Machine Learning.

## Dataset

The Iris dataset contains the following features:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width
* Species

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-Learn

## Project Steps

1. Data Loading
2. Data Analysis
3. Data Visualization
4. Feature Encoding
5. Model Training
6. Model Evaluation

## Model Used

* Random Forest Classifier

## Results

The model successfully classified Iris flowers into their respective species with high accuracy.
