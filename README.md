# CODSOFT Data Science Internship

This repository contains the projects completed as part of the CODSOFT Data Science Internship program. The projects focus on data analysis, visualization, machine learning, and predictive modeling using Python and popular data science libraries.

## Tasks Completed

### Task 1: Titanic Survival Prediction

* Analyzed the Titanic dataset.
* Performed data cleaning and preprocessing.
* Built a machine learning model to predict passenger survival.
* Evaluated model performance using classification metrics.

### Task 3: Iris Flower Classification

* Analyzed the Iris flower dataset.
* Visualized relationships between features.
* Built a classification model to identify flower species.
* Evaluated model accuracy and performance.

### Task 5: Credit Card Fraud Detection

* Analyzed credit card transaction data.
* Performed data preprocessing and normalization.
* Built a machine learning model to detect fraudulent transactions.
* Evaluated the model using Precision, Recall, F1-Score, and Accuracy.
